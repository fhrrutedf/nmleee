# 🌱 إضافة بيانات تجريبية

## ✅ تم إنشاء script لإضافة بيانات تجريبية!

### 📦 ما سيتم إضافته:

1. **مستخدم تجريبي** 👤
   - البريد: `demo@manasadigital.com`
   - كلمة المرور: `demo123`
   - Username: `demo`

2. **5 منتجات رقمية** 📦
   - كتاب JavaScript
   - قالب WordPress
   - مجموعة أيقونات
   - دليل التسويق بالعمولة
   - صور مخزون

3. **3 دورات تدريبية** 🎓
   - دورة تطوير الويب
   - دورة التصميم الجرافيكي
   - دورة التسويق الرقمي

4. **3 كوبونات خصم** 🎫
   - WELCOME50 (خصم 50%)
   - SAVE20 (خصم 20 ج.م)
   - FIRST10 (خصم 10%)

5. **4 تقييمات** ⭐
   - تقييمات على بعض المنتجات

---

## 🚀 كيف تضيف البيانات؟

### في PowerShell النفّذ:

```powershell
npm run db:seed
```

**هذا كل شيء!** ✨

---

## 🎯 بعد إضافة البيانات:

### 1. سجّل دخول:
```
البريد: demo@manasadigital.com
كلمة المرور: demo123
```

### 2. اختبر المنصة:
- ✅ شاهد المنتجات في `/dashboard/products`
- ✅ شاهد الدورات في `/dashboard/courses`
- ✅ شاهد الكوبونات في `/dashboard/coupons`
- ✅ شاهد Analytics في `/dashboard/analytics`

### 3. اختبر صفحة البائع:
```
http://localhost:3000/demo
```

## 🔄 إعادة تشغيل البيانات:

إذا أردت حذف كل شيء والبدء من جديد:

```powershell
# احذف قاعدة البيانات
npx prisma db push --force-reset

# أضف البيانات مرة أخرى
npm run db:seed
```
