## 🔧 الإعداد والتشغيل:

### 1. المتطلبات:
```
✅ Node.js
✅ MongoDB Atlas
✅ Stripe Account (اختياري)
✅ Cloudinary Account (اختياري)
✅ Novu Account (اختياري)
```

### 2. ملف .env:
```env
# Database
DATABASE_URL="mongodb+srv://..."

# NextAuth
NEXTAUTH_SECRET="..."
NEXTAUTH_URL="http://localhost:3000"

# Stripe (اختياري)
STRIPE_SECRET_KEY="sk_test_..."
STRIPE_PUBLISHABLE_KEY="pk_test_..."

# Cloudinary (اختياري)
CLOUDINARY_CLOUD_NAME="..."
CLOUDINARY_API_KEY="..."
CLOUDINARY_API_SECRET="..."

# Novu (اختياري)
NOVU_API_KEY="..."
NOVU_APP_ID="..."
```

### 3. التشغيل:
```bash
# تثبيت المكتبات
npm install --legacy-peer-deps

# إنشاء قاعدة البيانات
npx prisma generate
npx prisma db push

# إضافة بيانات تجريبية
npm run db:seed

# تشغيل المشروع
npm run dev
```
